# 👤 Thành viên 3: Trần Xuân Hướng
* **MSSV:** 2001230339
* **Vai trò:** Kỹ sư Phân tích Dữ liệu & Đánh giá (Data Analyst & Evaluation)
* **Đề tài phụ trách:** Chia tập dữ liệu, chuẩn hóa ảnh, tính toán Loss/Accuracy và vẽ biểu đồ hiệu năng (ROC-AUC).

---

## 📂 Danh sách các file phụ trách:
1. **`tienxulyanh.py`**: Chia bộ dữ liệu theo tỷ lệ chuẩn 7:2:1 (Train: 70%, Val: 20%, Test: 10%), dọn dẹp thư mục rác hệ thống.
2. **`phantichthongso.py`**: Tính toán các thông số huấn luyện và đánh giá mô hình.
3. **`phantichdulieu.py`**: Phân tích phân phối của bộ dữ liệu.
4. **`run_video_inference.py`**: Giao diện phụ bằng Tkinter để kiểm tra suy luận luồng video và ảnh nhanh chóng.
5. **`Phan_3_Huong_Dan_Train_Inference.docx`**: Tài liệu Word chi tiết về tiền xử lý dữ liệu và đánh giá mô hình.

---

## 🛠️ Hướng dẫn chạy nhanh:
```bash
# 1. Thực hiện chia tập dữ liệu 7:2:1
python tienxulyanh.py

# 2. Chạy giao diện phụ để kiểm thử nhanh video
python run_video_inference.py
```
